# Relationships are document-level edges and groups, with one denormalized convenience field

Resolution and subsequent history are recorded as document-level edges (from/to citation ids); parallel and string citations are document-level groups (member id lists). Citations themselves carry no relationship arrays — except one deliberate denormalization: a short form's `refersTo` mirrors its resolution edge, because it is the single link every consumer wants in one hop. The 0.x model encoded relationships redundantly per citation (`resolvedTo` index + `resolvedToId`, `groupId` + `stringCitationIndex/Size/Group`), which drifted; the invariant `refersTo === edge(from).to` is enforced by `validateDocument` so this one permitted duplication cannot. Consequence: n-ary facts exist exactly once, new relationship kinds never touch citation shapes, and edge tables map 1:1 to relational storage.
