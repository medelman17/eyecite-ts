# v1 has no plugin layer; the reporter source is the only extension seam

The v1.0.0 public interface is one deep surface — `extract` and `annotate` — with a single extension seam: the reporter source (two shipped adapters: the compact built-in table and the full database from `eyecite-ts/reporters`; test fakes are a third use). A full plugin design was drafted during the v1 redesign (custom recognition patterns, statute-code data entries, cleaner chains, swappable short-form resolvers, a read-only pipeline observer — each seam named two candidate adapters) and deliberately deferred: apart from reporters, every seam had only one *real* adapter today, and a config surface frozen at 1.0.0 is the hardest interface to walk back. Opening a seam later is a minor-version addition; the drafted design is the blueprint when a second adapter materializes. The `x-*` kind namespace is reserved now so plugin-produced kinds can arrive later without breaking exhaustiveness checking on the citation union.
